### Quick Start Guide

```bash
# 1. Navigate to the project directory
cd "C:\Users\bhask\.gemini\antigravity\scratch\ecogenesis"

# 2. Install dependencies (if not already installed)
npm install

# 3. Start development server
npm run dev

# 4. Or build and run production preview
npm run build
npm run preview
```

The application will be live at `http://localhost:5173/`.

### Key Architectural Modules

1. **Environmental Intelligence Dashboard**: Central telemetry with real-time Air Quality (PM2.5, PM10, NO2, SO2, O3), Solar Irradiance (GHI/DNI), Water Basin Storage (NWIC), Forest Carbon Flux (GFW), and CPCB India CAAQMS stations.
2. **AI Sustainability Assistant (GAIA)**: Step-by-step problem diagnosis, actionable recommendations, quantified benefits, implementation difficulty, financial ROI, and scientific citations.
3. **Personal & Enterprise Carbon Footprint Calculator**: Life-cycle emissions across transport, electricity (regional grid factors e.g. CEA India 0.713 kg/kWh), household energy, diet, and shopping, with benchmark comparisons against the 2.0-tonne Paris Agreement target.
4. **Sustainable Living Planner**: Personalized targets, habit streaks, 30-day sprints, and verified daily activity logging.
5. **Smart Waste Management**: 100+ item segregation catalogue, contamination prevention, and AI optical photo scanner.
6. **Water Conservation Intelligence**: Catchment hydrology rainwater harvesting calculator, domestic fixture audit, and 2-hour meter leak diagnostic.
7. **Renewable Energy Explorer**: NREL PVWatts-aligned rooftop solar simulator, payback horizon, and clean technology directory (Solar, Wind, Hydro, Geothermal, Biomass, Battery storage).
8. **Biodiversity & Nature Protection**: Real-time GBIF species occurrences, pollinator guide, and citizen science observation tool with a 1.5 km location privacy mask.
9. **Global Geospatial Action Map**: Interactive Leaflet dark tile map with verified restoration and clean energy installations worldwide.
10. **Community Sustainability Network**: Launch, join, and track verified local initiatives.
11. **Executive ESG Reports**: Printable report and audit-compliant CSV export.

### Real-World Data Ingestion Sources

- **Open-Meteo**: Hourly CAMS European & NOAA GFS air quality and meteorological forecast.
- **NASA POWER**: Satellite all-sky downward solar irradiance (GHI) and surface temperature.
- **GBIF**: Global Biodiversity Information Facility live Darwin Core occurrence records.
- **CPCB India / data.gov.in**: Central Pollution Control Board Continuous Ambient Air Quality Monitoring Stations.
- **Copernicus Climate Service**: ERA5 global surface temperature anomaly (+1.48°C) and CAMS atmospheric CO2 (426.9 ppm).
- **OpenAQ**: Global regulatory air quality monitor harmonization.
- **Global Forest Watch**: Hansen / UMD Landsat 30m tree cover loss and carbon sink modeling.
- **NWIC / India-WRIS**: Central Water Commission monitored reservoir storage and groundwater stage.
